## How to Run Locally
1. Clone the repository:
    ```bash
    git clone https://github.com/your-username/your-repository.git
    ```
2. Install the required dependencies:
    ```bash
    pip install -r requirements.txt
    ```
3. Run the app locally:
    ```bash
    streamlit run app.py
    ```
